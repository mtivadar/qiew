Drop TerminusTTF-*.ttf (or any monospaced .ttf/.otf) here, or in ~/.qiew/fonts,
and qiew will register it at start-up. Terminus is preferred when present;
otherwise the platform monospace font is used (Menlo / Consolas / DejaVu Sans Mono).
Terminus TTF: https://files.ax86.net/terminus-ttf/  (SIL Open Font License)
